gta-shorts-bot

gta-shorts-bot is a personal automation project run by its owner. It watches a small list of Twitch streams, saves highlight clips, and posts them as YouTube Shorts on the owner's own YouTube channel.

The app is not a public service. It is used only by its owner, and its source code is private.
